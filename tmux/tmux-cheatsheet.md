# Tmux Cheat Sheet

## Concepts

```
tmux tree:
  Server (running in background)
    ├─ Session (collection of windows)
    │    ├─ Window (tab, full-screen)
    │    │    ├─ Pane (split, like vim)
    │    │    └─ Pane
    │    └─ Window
    └─ Session
```

Detach and reattach later — everything keeps running.

## Setup (this machine)

- Config: `~/.config/tmux/tmux.conf`
- Colors: generated by wallust from wallpaper (`~/.config/tmux/colors.conf`)
- `tmux` aliased to `tmux -u` (required for nerd font icons)
- `$TERM` inside tmux = `tmux-256color`

## Starting / Stopping

| Command | Action |
|---------|--------|
| `tmux` | New session (named 0) |
| `tmux new -s work` | New session named "work" |
| `tmux ls` | List sessions |
| `tmux a` | Attach to last session |
| `tmux a -t work` | Attach to session "work" |
| `tmux kill-session -t work` | Kill session |

## Prefix: `C-b`

All commands start with prefix: hold **Ctrl**, tap **b**, release both, then command key.

## Panes (splits)

| Binding | Action |
|---------|--------|
| `C-b \|` | Split vertical (left/right) |
| `C-b -` | Split horizontal (top/bottom) |
| **`Alt+h/j/k/l`** | Move to pane (no prefix!) |
| `C-b M-H/J/K/L` | Resize pane 5 lines |
| `C-b z` | Zoom pane (toggle fullscreen) |
| `C-b q` | Show pane numbers |
| `C-b o` | Cycle to next pane |
| `C-b x` | Kill current pane |
| `C-b !` | Break pane into new window |

## Windows (tabs)

| Binding | Action |
|---------|--------|
| `C-b c` | New window (same directory) |
| `C-b n` | Next window |
| `C-b p` | Previous window |
| `C-b l` | Last (previous) window |
| `C-b w` | Interactive window picker |
| `C-b 0-9` | Window by number |
| `C-b ,` | Rename current window |
| `C-b .` | Move window to new number |
| `C-b R` | Renumber windows (close gaps) |
| `C-b &` | Kill current window |

## Copy Mode (vi keys)

Activate: `C-b Enter` or mouse scroll.

| Key | Action |
|-----|--------|
| `hjkl` | Move cursor |
| `g` | Top of history |
| `G` | Bottom of history |
| `v` | Begin selection |
| `V` | Select entire line |
| `C-v` | Rectangle (column) selection |
| `y` | Yank (copy) + exit mode |
| `Y` | Yank current line + exit mode |
| `/` | Search forward |
| `?` | Search backward |
| `n` / `N` | Next / previous match |
| `Escape` | Exit copy mode |
| Mouse drag | Select + auto-copy |

## Sessions

| Binding | Action |
|---------|--------|
| `C-b s` | Pick session from list |
| `C-b d` | Detach from session |
| `C-b D` | Detach other clients |
| `C-b $` | Rename session |

## Command Mode

`C-b :` opens a prompt. Useful commands:

```
:swap-window -s 1 -t 3      # swap window 1 and 3
:join-pane -s 2 -t 1        # move pane from window 2 to window 1
:move-window -r             # renumber windows
:source-file ~/.config/tmux/tmux.conf  # reload config
:set -g status off          # hide status bar (on to show)
:kill-session -a            # kill all sessions but current
```

## Config Reload

`C-b r` — sources `~/.config/tmux/tmux.conf` and shows "tmux reloaded".

## Tmux Resurrect / Continuum

| Binding | Action |
|---------|--------|
| `C-b C-s` | Save session state |
| `C-b C-r` | Restore session state |
| — | Auto-saves every 15 min |
| — | Auto-restores on tmux start |

## Plugin Management (TPM)

| Binding | Action |
|---------|--------|
| `C-b I` | Install plugins |
| `C-b U` | Update plugins |

## Fish Shell Shortcuts

Shell-level helpers (run from fish prompt outside tmux) that wrap common tmux ops and the resurrect plugin's save/restore scripts.

| Command | Action |
|---------|--------|
| `t` | Attach to last session (creates new if no server running) |
| `t <name>` | Attach to session `<name>` (creates if missing) |
| `tl` | List sessions (alias for `tmux ls`) |
| `tn <name>` | New session named `<name>` (alias for `tmux new -s`) |
| `tk <name>` | Kill session `<name>` (alias for `tmux kill-session -t`) |
| `tka` | Kill all sessions (alias for `tmux kill-server`) |
| `tsave` | Save current session state to disk (resurrect) |
| `trestore` | Restore last saved state and attach (resurrect) |

## Quick Reference

```
               SESSIONS                     WINDOWS                    PANES

  create ── tmux new -s name            C-b c                      C-b |   (vert)
  list   ── tmux ls                     C-b n/p/l                  C-b -   (horiz)
  attach ── tmux a -t name              C-b w                      Alt hjkl (move)
  detach ── C-b d                       C-b 0-9                    C-b z  (zoom)
  rename ── C-b $                       C-b ,                      C-b x  (kill)
```
